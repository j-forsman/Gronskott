# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately instead: go to the repository's **Security** tab and click **Report a vulnerability**. Only the maintainer can see the report.

Please include what you found, how to reproduce it, and which macOS version you used. You can expect a reply within a couple of weeks. This is a hobby project, so there is no bug bounty.

## Scope

Grönskott makes no network requests and stores nothing except screenshots you save yourself and two preferences (save folder and export format), so the most relevant issues are things like reading or writing files it shouldn't, or capturing more of the screen than the user selected.

Only the latest version on the `main` branch is supported.
